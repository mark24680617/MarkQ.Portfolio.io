Find a Job

An open-source job-application agent that writes each answer out of facts read from your resume, where TypeScript — not the Gemini prompt — rejects any draft that cites a fact the profile doesn’t hold or underlines a phrase missing from its own answer: one correction round, then a refusal naming what broke. Uncited prose renders plain and vouches for nothing. Built for the All Things Agentic hackathon.

Next.js TypeScript Gemini Cloud Run

LineCanary

Synthetic uptime monitoring for business phone lines and the voice agents answering them: a scheduled test call walks the caller journey, and its structured result is asserted against operator-written expectations, then diffed against that check’s own history so a quietly changed IVR menu surfaces as a named regression. A check gone quiet for 26 hours reads stale, never green. Built for the CALL-E hackathon and merged into CALL-E’s own skill registry.
